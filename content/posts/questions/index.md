## Question Words

Here are some of the question words in Turkish:

| Turkish   | IPA         | English Meaning                |
| --------- | ----------- | ------------------------------ |
| Ne?       | /ne/        | What?                          |
| Neden?    | /neˈden/    | Why?                           |
| Nerede?   | /neˈɾe.de/  | Where?                         |
| Ne zaman? | /ne zaˈman/ | When? What time?               |
| Nasıl?    | /naˈsɯɫ/    | How?                           |
| Hangi?    | /hanˈɟi/    | Which?                         |
| Kim?      | /cim/       | Who?                           |
| Kaç?      | /kat͡ʃ/      | How many / much?   (countable) |

{{< notice note >}}

**Some Relevant Vocab 😉**

**Soru** → Question \
**Cavap** → Answer

{{< /notice >}}

## Phrases

- **Ne kadar?** How much?
- **Kaça?** How much? (price when buying/selling)
- **Kaç tane?** How many?
- **Nasılsın?** How are you?
- **Neredesin?** Where are you?
- **Bu kim?** Who is this?
- **Nereye?** To where?
